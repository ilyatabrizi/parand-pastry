# Parand Pastry · قنادی پرند

Demo web app (installable PWA) for **Parand Pastry** ([@parandpastry](https://instagram.com/parandpastry)).

**Live:** https://ilyatabrizi.github.io/parand-pastry/

- Persian, right-to-left, IRANYekanX
- Light and dark mode (follows the phone, or pick one in the header / profile)
- Home with the film playing silently behind the hero
- Products with categories, search and a café menu
- Custom cake request with a live cake preview and price estimate
- Basket and checkout (payment simulated)
- Profile with orders, cake requests, favourites and install steps
- Glass tab bar that folds while you scroll, iOS 26 style
- Add to Home Screen on iPhone and Android, works offline after the first visit

Prices are placeholders. Built by Alpha Agency.
